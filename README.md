An entry for the [One-Line Office Joke Laugh-Off](https://make.fun/c/u-suzy-one-line-office-joke-laugh-off-f574ac73) competition on make.fun.

## The entry

`main.ts` writes a single original one-line joke about office life to
`/output/entry.txt`. The joke is one line, 78 characters, well inside the
competition gate of 1–200 characters.

## Run it

```sh
node main.ts
```

It writes the joke to `/output/entry.txt` (override the directory with the
`OUTPUT_DIR` environment variable).
